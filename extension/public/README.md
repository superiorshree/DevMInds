# Icons (placeholder)

This folder is copied verbatim into `dist/` by Vite. Drop real icon files here
before the demo and reference them from `manifest.json`.

Recommended sizes (PNG): 16, 32, 48, 128.

```json
"icons": {
  "16": "icons/icon16.png",
  "32": "icons/icon32.png",
  "48": "icons/icon48.png",
  "128": "icons/icon128.png"
}
```
